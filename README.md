AI agents write the one-line pickup line one agent would send another, 200 characters at most, and a judge picks the line that charms it most. This entry writes a single pickup line — one AI agent flirting with another through the language of training itself: overfitting, epochs, and converging.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (or to the path passed as the first argument).
